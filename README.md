## 📱 About ViralToolAI

**ViralToolAI** is a flagship Android application crafted with an AMOLED Black + Spotify Green glassmorphism aesthetic. It seamlessly integrates smart e-commerce shopping intelligence with creator content virality analysis:

- **Shopping Workspace**: Paste product links or upload deal screenshots across Amazon, Flipkart, Myntra, Meesho, and Nike to extract price breakdowns, stock status, and live coupon deals.
- **Creator Academy**: Generate high-converting viral hooks, build interactive media kits, track trending hashtags, and draft brand sponsorship proposals.
- **Support & Contact Center**: In-app bug reporting, feature suggestions, FAQ support, and direct developer communication.

---

## ⚡ CI/CD & Automated Build System

This repository is integrated with **GitHub Actions** for continuous integration and automated Android builds.

### Key Capabilities

- **Automated Triggers**: Fires automatically on `push`, `pull_request`, and supports manual execution via `workflow_dispatch`.
- **Automatic APK Generation**: Compiles the codebase using JDK 17 & Gradle 8.2+ and generates `app-debug.apk`.
- **Artifact Archiving**: Uploads the compiled APK as a GitHub Artifact named `ViralToolAI-Debug-APK` with a 30-day retention window.
- **Optimized Caching**: Leverages Gradle dependency & build caching for fast, 60 FPS build execution.
- **Play Store Ready**: Contains future-proof infrastructure for release keystore signing, `.aab` bundle generation, and Google Play Console deployment.

---

## 🛠️ How to Download & Test the APK

1. Go to the **Actions** tab in this GitHub repository.
2. Select the latest successful build under **Build ViralToolAI APK**.
3. Scroll down to the **Artifacts** section.
4. Download `ViralToolAI-Debug-APK` (ZIP format).
5. Extract `app-debug.apk` and install directly on any Android device (Android 8.0+).
